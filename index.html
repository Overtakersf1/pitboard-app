Live sync

The board syncs through a private GitHub repo — no more copy/paste. You need a repo and a fine-grained token with Contents: read & write on just that repo. Enter them once; after that the green dot means we're live.

PitBoard

A shared canvas for Sean & Claude — like a pit board, but both ways.

Drawing

  • Apple Pencil always draws. Fingers draw too, unless you flip the hand button to pan mode.
  • Two fingers always pan & pinch-zoom, whatever mode you're in.
  • Boxes, ellipses and decision diamonds: drag them out with the shape tools. Double-tap a shape (with Select) to give it a label.
  • Text tool: tap anywhere and type. Eraser deletes whole objects it touches.

The loop with Claude

  • Live sync (best): with the sync dot green, just draw — the board pushes itself, and Claude's edits appear on their own a few seconds after Claude makes them. Set it up via the dot button.
  • Put this board and the Claude app side by side in Split View, draw, and tell Claude what you want changed.
  • Fallback: Share → Copy for Claude → paste in chat; paste Claude's JSON back via Share → Load.

Tips

  • In Safari, use Add to Home Screen for a full-screen app feel.
  • Everything on the board is structured data — Claude can move your boxes, not just draw on top of them.
